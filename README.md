Application web de gestion des commandes

Présentation

Ce projet consiste à développer une application web permettant de gérer et de suivre les commandes, les clients, les paiements et les livraisons.

L'objectif est de centraliser les opérations et de faciliter le suivi des activités à travers une interface organisée selon les rôles des utilisateurs.

Fonctionnalités principales

- Gestion des utilisateurs et des accès
- Gestion des clients et des produits
- Saisie et suivi des commandes
- Gestion des paiements
- Suivi des livraisons
- Gestion des retours de consigne
- Suivi des produits défectueux
- Consultation des indicateurs d'activité

Technologies utilisées

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Chart.js

Installation

1. Installer un environnement local tel que XAMPP.
2. Copier le dossier du projet dans le répertoire "htdocs".
3. Créer la base de données dans phpMyAdmin.
4. Importer le fichier SQL fourni, s'il est présent dans le dépôt.
5. Configurer la connexion à la base de données.
6. Démarrer Apache et MySQL, puis accéder à l'application depuis un navigateur avec "http://localhost/nom-du-dossier".
